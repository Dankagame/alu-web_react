# alu-web_react

Course exercises for React, TypeScript, and Webpack.

## Webpack task 0

The basic Webpack exercise uses jQuery to add three paragraphs to the page. From `Webpack/task_0`, install dependencies and build the bundle with:

```sh
npm install
npm run build
```

Open `Webpack/task_0/dist/index.html` in a browser to view the result. Webpack generates `dist/main.js`; the generated bundle is ignored by Git.
